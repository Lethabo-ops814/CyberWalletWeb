# CyberWallet

## Personal Finance Management System

CyberWallet is a digital financial management system designed to assist individual users and small business owners with managing their finances.

The system consists of a responsive website and a mobile application that work together as an integrated financial management solution.

## Project Purpose

The purpose of CyberWallet is to provide users with a convenient platform for managing their financial information, monitoring income and expenses, viewing financial statistics and accessing additional financial services.

## Main Features

### Financial Management
- Record and manage income
- Record and manage expenses
- Manage financial transactions
- Create and manage budgets
- Manage financial categories
- Monitor financial balance

### Financial Planning and Analysis
- View financial statistics
- Analyse income and expenses
- Track spending
- Set savings goals
- Use the financial planner

### User Services
- User registration
- Secure login
- User profile management
- Financial statements
- Payment functionality
- Consultation booking
- Notifications

### Administrative Functions
The planned administrative functionality includes:
- User management
- Accountant management
- Payment management
- Booking management
- Message management
- Service management

## Platforms

CyberWallet is being developed across two platforms:

### Website
The website provides users with a responsive interface for accessing CyberWallet's financial management functionality.

### Mobile Application
The mobile application provides users with access to their financial information and planning features through a mobile interface.

Both platforms are designed to work with a shared backend and database.
